# 第十章 智能体编程实践

本章探讨 AI 智能体如何改变软件开发范式。不只是代码生成，而是深入 Agentic Coding 的核心——让 AI 作为自主智能体，参与需求理解、架构规划、代码编写、调试修复的全生命周期。从范式转移(Vibe → Agentic) → Agent Loop 原理 → 工具选择 → P-D-E-R 开发闭环 → 工程化实践的完整路径。

## 学习目标

完成本章后，你将能够：

1. **理解** Agentic Coding 的原理与思维范式
2. **掌握** Agent Loop、Stop Sequences、上下文窗口等核心概念
3. **选择** 适合场景的开发工具与平台
4. **构建** 高效的 AI 编码工作流与最佳实践

## 章节地图

本章按“先换脑子 → 再懂原理 → 再挑工具 → 再定方法 → 最后落到工程”的顺序展开：

- `10.1` 讲从 Vibe Coding 到 Agentic Coding 的范式转移
- `10.2` 拆解智能体循环：单步迭代、并发调度、停止序列与上下文窗口
- `10.3` 对比常见编程智能体工具的运行面、权限模型与指令文件
- `10.4` 讲 P-D-E-R 开发闭环与规范驱动、测试驱动的组合方式
- `10.5` 讲工程化实践：人类监督模型、检查点机制与复利工程
